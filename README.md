# 김프리즘 (Kimprism)

업비트·빗썸 시세와 바이낸스 시세를 실시간 달러/원 환율로 환산해 코인별 김치프리미엄을 보여주는 대시보드입니다. 같은 화면에 커뮤니티 채팅과 알림봇이 붙어 있습니다.

## 파일 구성

```
index.html           대시보드 + 채팅 + 주식 탭
privacy.html         개인정보처리방침 (애드센스 심사에 필요)
realtime.js          업비트·바이낸스 웹소켓 직접 연결, 김프를 브라우저에서 계산
chat-client.js       채팅 폴링 (탭 숨기면 정지, 조용하면 간격 자동 완화)
api/prices.js        시세·환율 조회와 김프 계산 — 빗썸 선택 시에만 사용
api/chat.js          채팅 저장 + 도배·스캠 방어
api/stocks.js        코스피·코스닥 시세
api/hyperliquid.js   하이퍼리퀴드 주식 퍼프 베이시스, 오라클 이탈 감시
vercel.json          함수 실행 지역 설정
```

업비트를 고르면 브라우저가 거래소 웹소켓에 직접 붙으므로 시세 관련 서버 호출이 없습니다.
빗썸은 웹소켓 경로가 없어 `api/prices.js` 를 5초마다 씁니다.

## 배포

1. 이 파일들을 GitHub 저장소 루트에 올립니다.
2. Vercel에서 해당 저장소를 Import 합니다. 프레임워크는 **Other**, 빌드 명령은 비워 둡니다.
3. Deploy 후 주소로 접속합니다.

## 배포 직후 꼭 확인할 것

브라우저에서 `배포주소/api/prices` 를 직접 열어 보세요. 정상이면 이런 모양의 JSON이 나옵니다.

```json
{ "ok": true, "canComputePremium": true, "fx": { "rate": 1380.5 }, "coins": [ ... ] }
```

- `coins` 가 비어 있고 `errors` 에 `binance` 가 보이면 → 함수가 미국 지역에서 실행돼 바이낸스가 차단(HTTP 451)한 경우입니다. Vercel 프로젝트 **Settings → Functions → Function Region** 을 `Seoul (icn1)` 로 바꾸고 다시 배포하세요.
- `errors` 에 환율 실패만 있으면 → 국내 시세는 나오지만 김프 칸이 비어 있습니다. 잠시 후 자동 복구됩니다.

사이트는 시세를 못 받으면 **숫자를 만들어 채우지 않고 비워 둡니다.** 화면에 값이 보이면 그건 실제 거래소 값입니다.

## 채팅을 영구 저장하려면

기본 상태에서는 채팅이 서버 메모리에 임시 저장되고, 서버가 잠들면 지워집니다. 영구 저장을 원하면:

1. [Upstash](https://upstash.com) 에서 무료 Redis DB를 만듭니다.
2. Vercel **Settings → Environment Variables** 에 아래 두 개를 추가합니다.
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
3. 다시 배포하면 채팅 패널에 "임시 저장" 표시가 사라집니다.

## 알림봇

- **시세알림봇** — 실제로 받아온 비트코인 가격이 10분 기준점 대비 0.5% 이상 움직이면 알립니다. 수치는 `index.html` 의 `MOVE`, `WINDOW` 에서 조정합니다.
- **고래알림봇** — 바이낸스 선물 강제청산 스트림을 브라우저에서 직접 구독해 10만 달러 이상 청산만 알립니다. 기준은 `MIN_USD` 에서 조정합니다.

둘 다 시뮬레이션이 아닌 실데이터입니다.

## 주식시장 탭

`api/stocks.js` 가 공개 시세 엔드포인트에서 코스피·코스닥 주요 종목 가격과 등락률을 가져옵니다. API 키가 필요 없고 1분마다 갱신됩니다.

종목은 파일 상단 `KOSPI`, `KOSDAQ` 배열에 티커와 이름으로 들어 있습니다. 바꾸려면 그 줄만 수정하면 됩니다 (코스피는 `.KS`, 코스닥은 `.KQ` 를 붙입니다). 시가총액 순위는 수시로 바뀌므로 "주요 종목"으로 표기했습니다.

실시간 호가와 분봉까지 필요하면 한국투자증권 오픈API(무료, 계좌 필요) 키를 받아 이 파일의 조회 부분만 교체하면 됩니다.

## 채팅 도배·스캠 방어

모든 검사는 `api/chat.js` 안에서, 즉 서버에서 합니다. 클라이언트 검사는 개발자도구로 우회되므로 방어로 치지 않습니다.

| 항목 | 기준 | 바꾸는 곳 |
| --- | --- | --- |
| 순간 속도 | 10초에 5개 | `BURST_WINDOW`, `BURST_LIMIT` |
| 지속 속도 | 60초에 20개 | `SUSTAIN_WINDOW`, `SUSTAIN_LIMIT` |
| 자동 차단 | 5분 내 5회 위반 → 30분 금지 | `VIOLATION_LIMIT`, `BAN_SECONDS` |
| 차단 문구 | 링크·지갑주소·메신저 아이디 | `SCAM_PATTERNS` |
| 사칭 닉 | 관리자·운영자·알림봇 등 | `RESERVED_NICKS` |

닉네임 옆의 `#3F2A` 표식은 서버가 IP 해시로 붙입니다. 클라이언트가 위조할 수 없고, 같은 사람은 하루 동안 같은 값이 나오므로 남의 닉을 베껴도 표식이 달라 사칭이 드러납니다. **IP 원본은 저장하지 않습니다.**

해시 소금은 `CHAT_SALT` 환경변수로 따로 줄 수 있고, 없으면 Upstash 토큰을 씁니다.

## 광고를 붙이기 전에

1. **Vercel Pro 로 전환** — Hobby 플랜은 상업적 이용이 금지됩니다. 레퍼럴 수익이나 광고가 있으면 약관 위반입니다.
2. **도메인 연결** — 애드센스는 소유를 증명할 수 있는 도메인이 필요합니다. `vercel.app` 하위 주소로는 신청이 안 됩니다.
3. **`privacy.html` 의 문의 이메일을 채울 것** — 지금은 자리만 비워 뒀습니다. 심사에서 확인합니다.
